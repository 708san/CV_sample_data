# Festival icon LoRA dataset

174 training PNG images (512×512) and `metadata.jsonl` for LoRA training. The six stage-related images (`music_stage`, `stage_lights`) have intentionally been excluded for the lesson’s held-out generation task.

Use the Colab notebook to fetch only this case using GitHub Contents API. Trigger word: `universal_icon_style`.

The original 135 images are published with creator permission; no standard open license has yet been selected.
